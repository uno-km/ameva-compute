2. PRE-PATCH DEFECT ISOLATION (ZERO-HYPE GROUND TRUTH)
--------------------------------------------------------------------------------
Pre-patch malformed GGUF execution terminated with SIGBUS-compatible exit code 135.
The parser contained both unchecked mmap-boundary advancement and alignment-unsafe direct integer dereferences.
The exact faulting instruction was not isolated.

SIGBUS_REPRODUCED=true
EXACT_FAULT_SITE=NOT_ISOLATED
LIKELY_CAUSES=unchecked mapped-range access, alignment-unsafe reads

Vulnerability Details in Unpatched Code:
  1. Direct Memory Dereferences: Unaligned *(const uint64_t*)ptr and *(const uint32_t*)ptr casts on ARM64.
  2. ne[4] Heap Buffer Overflow: GgufTensor defines uint64_t ne[4]. When n_dims > 4, loops clobbered
     subsequent struct members and heap chunks.
  3. Unchecked Range Advancement: Pointers advanced without verifying cur + size <= end.
  4. ALIGN_UP Underflow: general.alignment == 0 caused division by zero and arithmetic wrapping.
  5. Unbounded Memory Allocations: tensor_count and metadata_kv_count lacked sane element and byte limits.

3. POST-PATCH ARCHITECTURE: GgufReader BOUNDED PARSER
--------------------------------------------------------------------------------
The parser was completely refactored with a stateful bounded reader architecture:
  - Structure: GgufReader encapsulates cur and end pointers.
  - Invariants: reader_can_read(bytes) enforces bytes <= (size_t)(r->end - r->cur).
  - Explicit Unsigned Shifts: Every byte is cast to ((uint32_t)r->cur[i]) or ((uint64_t)r->cur[i])
    prior to shifting, preventing signed integer promotion issues on high-bit words.
  - Safe Math Helpers: checked_mul_u64 and checked_align_up guard against integer wrap-around.
  - Safe Range Invariant: offset <= available && size <= available - offset prevents addition overflow.
  - Zero Dead Code: Unused helper functions (reader_read_u8, reader_read_u16, reader_read_f64) were
    eliminated. All remaining helpers are actively invoked in production parsing paths.
  - Sane Resource Budgets:
      * GGUF_MAX_METADATA_KV_COUNT        : 65,536 entries
      * GGUF_MAX_TENSOR_COUNT             : 65,536 entries
      * GGUF_MAX_TOTAL_METADATA_BYTES     : 16 MB max for metadata section
      * GGUF_MAX_TOTAL_TENSOR_ALLOC_BYTES : 16 MB max for GgufTensor array
      * GGUF_MAX_STRING_LEN               : 65,536 bytes
      * GGUF_MAX_RECURSION_DEPTH          : 16 levels
  - Fail-Closed Guarantees: ac_gguf_open cleans up tensors, unmaps memory (munmap), closes fd,
    and sets *out_model = NULL on every failure condition.
