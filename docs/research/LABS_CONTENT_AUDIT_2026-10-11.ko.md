## 0. 긴급: 운영 사이트 보안 결함 (게시물 내용과 별개)

`api/labs.js`의 관리 엔드포인트 `reset_database`(posts·comments TRUNCATE), `force_seed`(posts TRUNCATE 후 재삽입),
`debug_db`(스키마와 메타 노출)의 인가 조건은 다음과 같습니다.

```js
if (!isLocalRequest(req) && process.env.NODE_ENV === 'production' && !req.headers['x-local-secret']) → 403
```

- `x-local-secret` 헤더는 **값을 확인하지 않고 존재 여부만** 봅니다. 아무 값이나 보내면 통과합니다.
- `isLocalRequest`는 `Host`, `Origin`, `Referer` 헤더에 `localhost`가 들어 있으면 참입니다. 이 헤더들은 요청자가 임의로 정할 수 있습니다.
- 따라서 외부의 누구든 POST 한 번으로 Labs 게시물과 댓글 테이블을 비울 수 있습니다. `TRUNCATE` 후에도 `labs_meta`의 시드 버전은 남아 있으므로,
  다음 `SEED_VERSION` 변경 전까지는 게시물이 다시 채워지지 않습니다.
- 코드 검토로 확인했고, 운영 사이트에 대해서는 시험하지 않았습니다.
- **권고:** 환경 변수의 비밀값과 상수 시간으로 비교하고, 환경 변수가 없으면 거부합니다. `Host`·`Origin`·`Referer` 기반 판정은 제거합니다.

## 3. C등급: 여러 게시물에 걸친 체계적 문제

- **C1 하드코딩된 "검증" 코드 셀:** 32편(#4, #9, #10, #12, #15~#23, #25~#29, #34, #38~#41, #47, #48, #52, #54, #55, #57, #65~#67)에 리터럴 값을 assert하고 "100% Deterministic … PASS"를 출력하는 셀이 있습니다.
  예: #55는 저장소 11개를 `tests_pass: True`로 직접 적은 뒤 "11/11 100% Green PASS"를 출력합니다. 측정이 아닌 시뮬레이션을 검증처럼 보이게 하므로,
  프로젝트 규칙(강제 PASS·하드코딩 결과 금지)과 충돌합니다.
- **C2 영문판 상투 부록:** 23편(#3, #5~#8, #11, #12, #14, #16, #17, #20, #23, #24, #27~#29, #38~#41, #47, #48, #52)의 영문판 끝에 장 내용과 무관한 "Extended Engineering Appendix"가 붙어 있고,
  "guaranteeing zero proprietary vendor lock-in and 100% reproducible" 같은 문구가 들어 있습니다.
- **C3 라이선스 표기 모순:** SPDX 헤더는 `Apache-2.0 OR Commercial-License`인데 본문 거버넌스 절은 "AGPL-3.0, BSL, 듀얼 라이선스 도입"이라고 씁니다(11편: #1, #2, #33~#37, #47, #48, #52, #65).
- **C4 종료 코드 0을 성공 근거로 사용:** #67 "Process Exit Code 0 → 100% Deterministic". 프로젝트 원칙("프로세스 정상 종료만으로는 GPU 실행의 증거가 아님")과 충돌합니다.
- **C5 과장 표현:** "세계 최초"(#48, #52, #71. #65는 정정 완료), "완치·박멸·기적·압도적·폭풍 타이핑·총살·처형" 등.
  공개 페이지 `docs/benchmarks.html`의 제목에 비속어("TTS 개지랄기")가 있습니다.
